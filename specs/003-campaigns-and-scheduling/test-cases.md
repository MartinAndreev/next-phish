# Documentation test cases

## Preconditions

- Review `research/campaigns-and-scheduling.md` and `spec.md` from the same commit.
- Treat the official Gophish Campaigns page as authority only for statements labeled
  Gophish behavior.
- Treat confirmed decisions in `spec.md` as authority for NextPhish behavior.
- Do not validate or imply runtime implementation; this feature changes documentation
  only.
